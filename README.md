## Padre Gino's Pizza Order App - Complete Intro to React, v9 Course

This repository was created by following the instruction in the [Complete Intro to React, v9][fem] course on Frontend Masters.
[![Frontend Masters](https://static.frontendmasters.com/assets/brand/logos/full.png)][fem]

## Setup Instructions

`Node.js version 20` is recommended to run this project.

```bash
git@github.com:guanguer/padre-ginos-react-app.git
cd padre-ginos-react-app.git
npm install
```

## Run the Application

```bash
npm run dev
```

## Build the Application

```bash
npm run build
```
